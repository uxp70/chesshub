    Bot ratings

    These bots are powered by Stockfish 19 in your browser, limited to each rating with Skill Level / UCI_Elo. The eval bar and Game Review use full-strength Stockfish.

    How this works

    • Ratings: Sprout 300 · Pixel 600 · Mira 900 · Jonah 1200 · Zara 1500 · Odin 1850
    • Strength: Skill Level for lower bots, UCI_Elo strength limiting for 1500 and 1850
    • Analysis: hints search to depth 24; Game Review searches every move at depth 18
    • Local: Stockfish 19 lite (NNUE WASM) runs in a Web Worker; no server, no API keys
